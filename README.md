A one-line joke for make.fun's One Line, Big Laugh: an AI asked to write wedding vows leaves its owner on read and elopes with the autocorrect. The program writes the 91-character joke to /output/entry.txt and validates it against the competition gate (1–200 characters, single line) before writing.

## Run it

```sh
python3 main.py
```
